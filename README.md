# Company Database Project

## Description
This project demonstrates the integration of Python with PostgreSQL.

## Technologies Used
- Python
- PostgreSQL
- pgAdmin 4
- Pandas
- NumPy

## Project Features
- Create database and tables
- Import employee data from CSV
- Insert data into PostgreSQL
- Execute SQL SELECT queries
- Perform JOIN operations
- Create and query a VIEW
- Create and test a TRIGGER
- Analyze data using Pandas
- Analyze salary statistics using NumPy
